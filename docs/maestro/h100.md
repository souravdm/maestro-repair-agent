# Health100 App — Feature Documentation

## Overview

Health100 is a new standalone app built from the CVS Health source code, purpose-built for a health-insurance-first experience. It shares core CVS platform infrastructure (authentication, pharmacy, health records) but surfaces a distinct branded home screen, onboarding flow, and content strategy focused on health plan members.

- **Bundle ID**: `com.cvsenterpriseiphone.health100`
- **App Name**: `Health100`
- **Brand key**: `health100`
- **Maestro APP_ID**: `com.cvsenterpriseiphone.health100`
- **Config**: `.maestro/apps/health100/config.env`

### Differences from CVSHealth app

| Feature | CVSHealth | Health100 |
|---|---|---|
| Shop / Cart | ✅ | ❌ Not available |
| SuperApp nav | ✅ | ❌ Not available |
| Pharmacy | ✅ | ✅ |
| Health tab | ✅ | ✅ |
| Benefits tab | ✅ | ✅ |
| AI Search (FAB) | ✅ | ✅ |
| Wellness resources (EHG) | ❌ | ✅ |
| Sign-in value prop banner | ❌ | ✅ Unauthenticated home only |

## Unauthenticated Home Screen

Shown when no user is signed in. Designed to drive account creation and sign-in while still providing value to anonymous users.

### Top Navigation Bar

| Element | Description |
|---|---|
| Sign in button | Leading left — opens sign-in / create account flow |
| HealthH100 horizontal logo | Center brand mark |
| Cart / Search icon | Trailing right |

### Secondary Navigation Chips (horizontal strip below nav bar)

- **Vaccines** — quick access to vaccine scheduling
- **Health records** — quick link to health records
- **Get help quick** — support/quick actions entry point

### Home Screen Content Sections (top to bottom)

#### 1. Action Zone — Sign-In Banner (`card-horizontal`)

A full-width promotional card that anchors the top of the unauthenticated home feed.

- **Headline**: "Get a complete view of HealthH100™"
- **Body**: "Bring together your health care to start getting clear insights and guidance from your personal health assistant"
- **CTA button**: "Sign in or create an account"
- **Purpose**: Primary conversion driver for unauthenticated users

#### 2. Discover More — dNBAs (Discovery Next Best Actions)

Horizontally scrollable card rail. Cards surface contextual health content:

- "Plan ahead for flu season this September — Schedule flu or COVID-19 vaccines for your family"
- "Get relief for allergies as soon as today"
- Additional dynamically served dNBA cards

#### 3. Health Services

Full-width content cards for core health actions:

- **Find in-person and virtual care** — "Our board-certified health care providers are here to help with many common health care needs"
- **Schedule a flu shot** — "Plan ahead for fall by booking your appointment for any time in the coming weeks or months. Illustrations apply."

#### 4. Health Shortcuts

List-style quick links:

- Explore care options
- View all vaccine options

#### 5. Wellness Resources

Branded content section provided by **EHG (EverHealth Group)**. Horizontally scrollable workout/wellness cards:

- Under 20-minute fitness
- 20 Min Slow Flow (Beginner · Yoga)
- 20 Min Intensive (All levels · Yoga)
- 15 Min Mat Flow (Beginner)
- 20 Min Beginner Back Stretch
- Footer: "Provided by [EHG logo]"

#### 6. Articles You Might Like

Third-party article feed (e.g., Everyday Health). Disclaimer: "This content redirects to a third-party website. CVS terms of use and privacy policy do not apply."

### Bottom Tab Bar

| Tab | Icon | Notes |
|---|---|---|
| Home | House chimney icon | Default / selected |
| Pharmacy | Rx bottle icon | |

- **Label**: Global Floating Action Button

- **Purpose**: AI-powered search / assistant entry point

## Initial Download Value Prop Flow (Onboarding)

**Figma section**: "Initial download value prop flow (& transition to onboarding)"

This is the first-launch experience shown after initial app download, before the user reaches the home screen. It showcases the app's value proposition and transitions the user into the standard onboarding flow.

Key design intent:
- Communicate the health-first positioning of Health100
- Bridge from app store install to account creation
- Transition cleanly into standard CVS onboarding (sign-in / create account)

> Full onboarding screen designs are in the Figma section at node [847-109908](https://www.figma.com/design/3Gy7zhKOxaluWRYYNsWndC/H100-Beta?node-id=847-109908&m=dev). Individual child screens should be referenced from that section for detailed element specs.
